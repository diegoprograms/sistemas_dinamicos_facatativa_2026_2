# Registro de decisiones

## Decisión 001

- El consumo observado será el punto de partida del modelo.
- Estado: aprobada.

## Decisión 002

- Clima y recurso hídrico se modelarán como subsistemas separados y conectados.
- Estado: aprobada.

## Decisión 003

- La planificación de cultivos se evaluará bajo escenarios húmedo, promedio y seco.
- Estado: provisional.

## Decisión 004

- La afirmación sobre asignación ineficiente del agua se manejará como hipótesis hasta contar con evidencia.
- Estado: aprobada.
